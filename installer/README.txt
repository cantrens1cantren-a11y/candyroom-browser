CANDYROOM: СБОРКА УСТАНОВЩИКА С ИКОНКОЙ

Добавлена иконка браузера с прозрачным фоном. Она встраивается в Candyroom.exe и используется для ярлыков. Если на значке ярлыка отображается старая картинка, обновите рабочий стол или перезапустите проводник Windows.

Это исходники для создания установщика, НЕ готовый установщик. В среде создания нет Windows и .NET SDK, поэтому сборка и работа не проверены.

1. На Windows 10/11 x64 установите .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
2. Распакуйте весь архив в новую папку. Подключитесь к интернету.
3. Запустите BUILD_INSTALLER.bat. Дождитесь окончания: при первой сборке скачиваются пакеты.
4. Готовый установщик: setup-output\CandyroomSetup.exe. Этот файл можно передавать отдельно от остальных файлов из архива.
5. Запустите установщик, выберите нужные опции и нажмите «Установить». Перед обновлением закройте браузер.

Установщик копирует браузер в %LOCALAPPDATA%\Candyroom\Application, создаёт ярлык в меню «Пуск», по желанию создаёт ярлык на рабочем столе и запускает браузер. Установка не требует прав администратора. В самом установщике включён .NET, отдельная установка .NET на компьютере пользователя не нужна.

ВАЖНО: на целевом компьютере также нужен Microsoft Edge WebView2 Runtime: https://developer.microsoft.com/microsoft-edge/webview2/ . Установщик НЕ скачивает и НЕ устанавливает WebView2 Runtime автоматически. Если его нет, установите отдельно.

Установщик не подписан цифровым сертификатом: Windows может показать предупреждение об неизвестном издателе. Удаление из «Установленных приложений» не настроено. Для ручного удаления закройте браузер, удалите папку %LOCALAPPDATA%\Candyroom\Application и его ярлыки. Данные сайтов и настройки в %LOCALAPPDATA%\Candyroom\BrowserProfile и settings.json сохраняются, пока не удалить их отдельно.

Внимание: установка поверх существующей версии перезаписывает файлы в папке приложения, но не удаляет старые дополнительные файлы. Если появилась ошибка, пришлите её полный текст.
