CANDYROOM BROWSER 5

Сборка в Windows 10/11 x64:
1. Установите .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0


2. Скачайте установщик : https://drive.google.com/file/d/1rWGigangsVXleyerMNEKZIlDU7Mtoj8U/view (кликабельно)


3. Запустите CandyroomSetup.exe и установите
4. Для запуска нужен Microsoft Edge WebView2 Runtime: https://developer.microsoft.com/microsoft-edge/webview2/
