CANDYROOM BROWSER 5

Сборка в Windows 10/11 x64:
1. Установите .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
2. Скачайте весь архив и вытащите папку installer
3. Распакуйте архив в НОВУЮ папку и запустите BUILD.bat. Нужен интернет.
4. Запустите publish\Candyroom.exe. Для переноса копируйте всю папку publish.
5. Для запуска нужен Microsoft Edge WebView2 Runtime: https://developer.microsoft.com/microsoft-edge/webview2/
